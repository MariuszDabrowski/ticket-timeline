# Project Instructions

## Committing
After completing each small feature or self-contained change, create a git commit before moving on to the next task. Do not include a `Co-Authored-By` trailer — commits should appear under the user's account only.

## Docs to keep in sync
When a change touches something referenced in either of these, update them in the same commit:
- **README.md** — user-facing feature descriptions, screenshots, install/usage steps.
- **src/views/StyleGuideView.vue** — the `#styleguide` catalog of shared UI primitives (buttons, form controls, modals, pills, badges, toasts, palette, typography). If you add/rename/remove a shared class, restyle a primitive, or change a modal size tier, update the corresponding entry so the catalog stays a faithful reference.
